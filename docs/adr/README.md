# Architecture Decision Records (ADRs)

This directory contains Architectural Decision Records for CASHFLOW INFINITY: OMNIVERSE.

Each record documents an architectural decision made, its context, consequences, and alternatives considered.

## Format

ADRs follow the lightweight Michael Nygard format:
- **Title**: `NNNN-short-title.md`
- **Status**: [Proposed | Accepted | Superseded | Deprecated]
- **Context**: The problem and forces shaping the decision.
- **Decision**: The change or architecture chosen.
- **Consequences**: Positive, negative, and neutral trade-offs.
