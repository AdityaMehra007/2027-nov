# OMNIA Master Backlog Operating Guide

All work must have a unique task ID, owner, priority, acceptance criteria, status and evidence link.

Priority:
- P0: safety, security, foundational dependency or release blocker.
- P1: essential for first validated workflow.
- P2: important after initial proof.
- P3: exploratory or future.

Statuses:
Not started; Researching; Specified; In progress; In review; Testing; Blocked; Completed; Rejected; Deferred.

A task is completed only if acceptance criteria are satisfied and evidence exists.

Weekly review:
1. What changed?
2. What is actually working?
3. What did tests prove?
4. What is blocked?
5. What risks increased?
6. What should be stopped?
7. What is the single highest-leverage next action?
