# Acceptance and Release Gates

## Product
- Target user and task are explicit.
- Core flow can be completed.
- Error and empty states exist.
- User data export/deletion behavior is documented.
- User research evidence supports the feature.

## Engineering
- Architecture and interfaces documented.
- Tests reproducible.
- Dependency and licence review completed.
- Error handling and observability implemented.
- Rollback and recovery plan available.

## Security and privacy
- Threat model current.
- Authentication and authorisation tested.
- Tenant isolation tested.
- Secrets controlled.
- Logging avoids leaking sensitive data.
- Critical findings resolved.
- Incident owner assigned.

## AI
- Representative evaluation set.
- Factuality and evidence metrics.
- Tool permissions and approval gates.
- Cost and latency tracked.
- Failure and escalation paths.

## Commercial
- Customer value evidenced.
- Pricing hypothesis tested.
- Unit economics estimated and labelled.
- Support and operational costs accounted.

No launch claim without evidence. A launch can be blocked for unresolved critical issues.
