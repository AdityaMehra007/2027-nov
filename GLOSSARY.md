# Domain Glossary: CASHFLOW INFINITY (OMNIVERSE)

This document establishes the canonical domain vocabulary for the repository. When discussing, designing, writing tickets, or creating issues, use these terms consistently.

## Core Concepts

### Core Alpha (Autonomous Commerce)
- **Conglomerate Engine**: The autonomous apex operational layer governing the commercial, software, and quant divisions.
- **Commercial Division**: The client acquisition, CRM prospector, and growth-kit delivery unit.
- **Software Division**: Micro-SaaS scaffolding, API generation, and billing gateway integration engine.
- **Quant & Capital Division**: Automated multi-strategy quantitative analysis, triangular arbitrage, and portfolio risk scanner.
- **Unified Settlement Adapter**: Multi-gateway financial abstraction layer interfacing with Stripe, Razorpay AutoPay (UPI), and Global RTGS.

### Core Beta (Aether Resilience Fabric)
- **Aether Fabric**: The geospatial, multi-hazard risk assessment and emergency relief allocation engine.
- **WGS84 Risk Engine**: Geospatial hazard and critical infrastructure indexing kernel.
- **Relief Allocation Matrix**: Autonomous optimization model for emergency shelter and resource routing.

### Governance & Security
- **Air-Gapped Security Governor**: Cryptographic defense layer that enforces HMAC-SHA256 verification and explicit sign-offs for high-value financial actions (> $10,000 USD).
- **PendingActionsQueue**: The staging queue where actions requiring manual human cryptographic sign-off are paused.
- **OmniSwarm Mesh**: Decentralized multi-agent peer-to-peer execution grid operating under high-throughput messaging.

## Conventions

- Always refer to financial movements as either **Reconciled Collected Revenue** or **Pipeline Value**.
- Distinguish between **Autonomous Tasks** (executable without manual intervention) and **Gated Operations** (requiring cryptographic sign-off).
