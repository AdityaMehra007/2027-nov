# CASHFLOW INFINITY: Micro-Agency & Revenue Engine

Use this skill to identify customer problems, generate high-converting Local Business Growth Kits, execute high-ticket Bangalore GCC enterprise business development, maintain the prospective client CRM, and track collected revenue.

## When to Use
- User asks to "generate growth kit", "find clients", "create pitch", "manage leads", "record payment", or "do business with Bangalore big companies / GCCs".
- Target markets:
  - **Local Commercial SMBs**: Cafes, restaurants, salons, gyms, retail, clinics, and professional services.
  - **Enterprise GCCs & Tech Giants (Bengaluru)**: Fortune 500 tech hubs across Outer Ring Road, Manyata Tech Park, Whitefield, Bagmane, and Electronic City.

## Operational Workflows

### 1. High-Ticket Bengaluru GCC Enterprise Pipeline (Big Companies)
To prospect, pitch, teardown, and close ₹25L–₹40L pilots and ₹1.5 Cr+ annual retainers with Bangalore GCCs:

```powershell
# 1. Discover target Fortune 500 GCCs by Bangalore tech corridor
python -m omniverse.cli enterprise-list --corridor OUTER_RING_ROAD

# 2. Generate a custom 'Proof-First' architectural teardown and 3-minute video script
python -m omniverse.cli enterprise-teardown --company "Target India" --workflow "supply-chain-reconciliation"

# 3. Generate 4-touch executive ABM sequence or 1-page boardroom brief
python -m omniverse.cli enterprise-outreach --company "Wells Fargo India" --one-pager

# 4. Generate legally binding 6-week pilot agreement (₹35L + 18% GST = ₹41.3L total)
python -m omniverse.cli enterprise-pilot --company "Mercedes-Benz R&D India" --fee 3500000 --contract

# 5. Generate CISO zero-egress VPC deployment and DPDP/RBI compliance whitepaper
python -m omniverse.cli enterprise-security --company "JP Morgan Chase" --cloud aws --dossier
```

### 2. Generate Local Business Growth Kit (SMBs)
To generate a 10-caption, 5-hook, WhatsApp catalog package for an SMB:
```powershell
python -m omniverse.cli generate-kit --business "Business Name" --niche "Category" --city "Bengaluru"
```

### 3. View Active Lead Pipeline
```powershell
python -m omniverse.cli leads
```

### 4. Pipeline Stages
1. `NEW`: Discovered prospect.
2. `QUALIFIED`: Verified contact person and willingness to evaluate.
3. `CONTACTED`: Sample demo / Growth Kit shared.
4. `PROPOSAL_SENT`: Commercial contract and pricing offered.
5. `WON`: Agreement reached and invoice issued.
6. `LOST`: Disqualified or declined.

### 5. Revenue Reconciliation Doctrine
Only funds confirmed received in bank/escrow count as `Collected Revenue`. Unsigned contracts remain categorized strictly as `Pipeline Value`.
