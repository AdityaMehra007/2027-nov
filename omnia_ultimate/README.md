**Status:** Programme blueprint + runnable local engineering foundation

## Important status boundary

The documents and code are a starting programme architecture. OMNIA is not incorporated, funded, staffed or partnered by virtue of this package. The code is a local prototype, not production infrastructure. It has no authentication, tenant isolation, external connectors, production secrets management or high-availability deployment. Do not expose its local HTTP server to the public internet.

The first practical objective is to validate a narrow user problem, then harden and extend the product with actual users, qualified staff and evidence.
