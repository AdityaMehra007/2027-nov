# How to Use the OMNIA Master Prompt

1. Attach the entire OMNIA package to ChatGPT Work.
2. Paste `docs/02_ULTIMATE_MASTER_PROMPT.md`.
3. Give access only to the repositories and files required for the current task.
4. Ask it to inspect before editing.
5. Require an artifact inventory and reproducible test results.
6. Give explicit approval before external actions or spending.
7. Use a new, scoped task for each milestone.
8. Keep the charter and backlog as the source of truth.
9. Update the ecosystem registry with dates and sources, not unverified claims.
10. Run weekly reviews and stop weak projects early.

Do not expect a prompt to create actual employees, funding, partnerships, external access, or autonomous work beyond available tools and permissions.
