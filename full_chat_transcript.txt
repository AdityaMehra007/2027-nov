# 2. The specialisation you mentioned: Kernel Engineering

<AsyncImageGroup query={["Linux kernel source code programming terminal","NVIDIA GPU CUDA parallel computing architecture","computer CPU GPU architecture motherboard technical visualization"]} aspectRatio="5:4" layout="bento"/>

Kernel engineering is one of the deepest technical specialisations.

A kernel is the central component of an operating system. It manages fundamental resources such as CPU time, memory, processes and hardware interactions.

But there are several related specialisations worth knowing:

| Specialisation | What they actually build |
|---|---|
| OS Kernel Engineer | Operating systems, device drivers and low-level resource management |
| GPU / CUDA Engineer | High-performance GPU computing and AI acceleration |
| Compiler Engineer | Programming language compilers and optimisation systems |
| Distributed Systems Engineer | Large-scale, fault-tolerant computing systems |
| Systems Programmer | Operating system tools, runtimes and performance-critical software |
| Embedded Systems Engineer | Software inside vehicles, machines, appliances and hardware |
| Database Engine Engineer | Database engines, storage and query-processing systems |
| Networking Engineer | High-speed networks, protocols and communication infrastructure |
| Cryptography Engineer | Encryption protocols, secure computation and authentication |

**My observation:** Kernel engineering is extremely specialised, but it isn't necessarily the best starting point for someone seeking the broadest job market. AI infrastructure, distributed systems and applied AI offer a wider combination of opportunities.
