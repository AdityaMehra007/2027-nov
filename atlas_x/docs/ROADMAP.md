# ATLAS technical roadmap

## R0 — Executable reference slice
- Go task control plane.
- Durable hash-chain audit log.
- Explicit external-action approval.
- Python deterministic job analysis baseline.
- TypeScript SDK and console.
- Rust policy reference.
- SQL schema and security model.

## R1 — Production-shaped Career OS
- Real identity provider and workspace membership.
- PostgreSQL persistence and tenant isolation.
- Job records, profile evidence and resume versions.
- Evaluation set and grounded AI workflows.
- Export/deletion, backups and audit review.

## R2 — Workflow runtime
- Durable workflow state and job queue.
- Idempotent connector execution.
- Per-tool capability grants.
- Approval service and action receipts.
- Event schemas and replay strategy.

## R3 — ATLAS Core
- Reusable context model.
- Tool registry and connector SDK.
- Model routing and evaluation service.
- Shared workflow definitions.
- Tenant-aware usage and cost metering.

## R4 — ATLAS Work and Studio
- One validated team workflow.
- Workflow editor only after core patterns stabilise.
- Developer API, scoped tokens and webhooks.

## R5 — Enterprise and ecosystem
- Admin controls, SSO/SCIM as demanded.
- Compliance programme and independent assessment.
- High availability, disaster recovery and support operations.
- Partner and developer ecosystem.

No stage is automatic. Each requires customer evidence, reliability, security and economic gates.
