## 1. PRODUCT VISION & CORE OBJECTIVES

CASHFLOW INFINITY: OMNIVERSE is the world's first unified autonomous enterprise operating system that couples hyper-velocity commercial software generation, automated client acquisition, multi-rail financial settlement, and mission-critical geospatial disaster resilience.

### Primary User Personas:
1. **Global Enterprise Client / CTO / VP Engineering**: Purchases high-velocity software engineering, SaaS deployment, and workflow automation services via self-service or GCC contract.
2. **GCC Treasury & Operations Director (Bengaluru / Singapore / London)**: Governs bulk cross-border corporate payments, ISO 20022 messages, vendor reconciliation, and cash logistics.
3. **Executive Conglomerate Governor / Fund Partner**: Monitors real-time consolidated financial performance, liquidity runways, asset health, and autonomous agent fleet operations.
4. **Resilience & Risk Commander**: Evaluates geopolitical and environmental risk scores across enterprise nodes, data centers, and global logistics corridors.

## 2. CORE USER JOURNEYS & EDGE CASE SPECIFICATIONS

### Journey 1: Autonomous Inbound Discovery to Verified Settlement
1. **Discovery**: Client discovers an organic comparison page generated by the Programmatic SEO Engine (e.g. `dist/seo_pages/nobroker-alternative.md` or `dist/seo_pages/hubspot-alternative.md`) or receives an autonomous video pitch.
2. **Order Intake**: Client selects a Tier-1 Service (`FULLSTACK_DEV`, `MARKETING_SUITE`, `ENTERPRISE_INTEGRATION`), specifies project parameters, and submits via API/Web interface.
3. **Autonomous Production**: The Code Factory and Marketing Factory autonomously generate production code, test suites, architecture docs, and CI workflows.
4. **Automated Quality Verification**: QA Governor executes linters, tests, and security scans. If tests fail, the self-healing loop patches issues automatically.
5. **Preview & Revision**: Client receives an interactive preview. If feedback is submitted, the Autonomous Revision Agent parses changes, edits source files, verifies tests pass, and rebuilds the bundle.
6. **Multi-Rail Settlement**: Client chooses payment method:
   - **UPI Instant Rail**: Dynamically generated NPCI-compliant UPI Intent QR code. Instant UTR callback reconciliation.
   - **Web3 Crypto Escrow**: Solana / Base USDC escrow contract address with cryptographic transaction hash validation.
   - **Corporate Bank Transfer**: ISO 20022 `pain.001` corporate credit transfer.
7. **License Release**: Upon ledger verification, production repository access and artifact ZIPs are released.

#### Edge Cases Handled:
- **Underpayment / Partial Payment**: System flags order as `PARTIALLY_SETTLED`, notifies client with remaining balance, and withholds repository unlocking until 100% threshold reached.
- **Client Malformed Revision Feedback**: Feedback with ambiguous or contradictory requests triggers an AI clarification prompt rather than silently corrupting code files.
- **RPC Fork or Transaction Reorg**: Web3 gateway waits for 12 block confirmations before marking transaction status as `CONFIRMED`.

---

### Journey 2: Bangalore GCC Enterprise Procurement & ISO 20022 Clearing
1. **Enterprise Deal Intake**: Bangalore GCC deal registered (e.g. 1000-seat GCC engineering transformation, $500,000 ACV).
2. **Pilot Governance Framework**: 3-stage pilot framework generated with formal entry/exit criteria, regulatory filings, and SLAs.
3. **Core Banking Settlement**: Enterprise issues vendor clearing instructions using ISO 20022 `pain.001` XML.
4. **Security Governor Evaluation**: Deals or payments exceeding $10,000 (Rs 8,30,000) are routed through the Security Governor requiring HMAC-SHA256 human-in-the-loop multi-sig approval.
5. **Execution & Statutory Compliance**: Settlement dispatched through NPCI UPI switch or RTGS (`pacs.008`), followed by automated generation of RBI Form A2 and LRS returns.

#### Edge Cases Handled:
- **Exceeded Daily Spending Limit**: Transactions exceeding `safety_budget_daily_usd` are blocked immediately with alert raised on Executive Cockpit.
- **Corrupted ISO 20022 XML Schema**: Schema validator detects malformed tags or missing BIC/IBAN and rejects with precise line-numbered diagnostic errors before submitting to banking switch.

## 3. API ENDPOINTS & SCHEMAS (OPENAPI 3.1 COMPLIANT)

### 3.1 Agency & Commercial Routes (`/api/v1/agency`)
- `POST /api/v1/agency/orders`: Create a new commercial job order.
  - **Request**: `{ "client_id": string, "service_type": "fullstack_dev" | "marketing_suite" | "automation_flow", "brief": string, "budget_usd": number }`
  - **Response (201)**: `{ "order_id": string, "status": "registered", "created_at": number }`
- `POST /api/v1/agency/orders/{order_id}/produce`: Trigger autonomous fulfillment.
  - **Response (200)**: `{ "order_id": string, "status": "completed", "deliverables": [...], "qa_verified": true }`
- `POST /api/v1/agency/orders/{order_id}/revisions`: Submit revision feedback to the Autonomous Revision Agent.
  - **Request**: `{ "feedback": string }`
  - **Response (200)**: `{ "revision_id": string, "qa_verified": true, "files_updated": [...], "zip_bundle_path": string, "summary": string }`
- `POST /api/v1/agency/payments/upi/generate`: Generate dynamic NPCI UPI intent & QR.
  - **Request**: `{ "order_id": string, "amount_inr": number, "payee_vpa": string }`
  - **Response (200)**: `{ "intent_url": string, "qr_payload": string, "reference_id": string }`
- `POST /api/v1/agency/payments/crypto/verify`: Cryptographically verify Web3 payment.
  - **Request**: `{ "order_id": string, "network": "solana" | "base", "tx_hash": string, "expected_usd": number }`
  - **Response (200)**: `{ "verified": boolean, "amount_settled_usd": number, "block_height": number }`
- `POST /api/v1/agency/daemon/cycle`: Trigger one autonomous cycle of the 24/7 background agent.
  - **Response (200)**: `{ "leads_scanned": number, "proposals_dispatched": number, "videos_scripted": number }`

### 3.2 Enterprise Bangalore GCC Routes (`/api/v1/bangalore`)
- `GET /api/v1/bangalore/stats`: Real-time GCC economic and banking metrics.
- `POST /api/v1/bangalore/deals`: Register a new enterprise capability center contract.
- `POST /api/v1/bangalore/banking/iso20022/transfer`: Ingest and execute an ISO 20022 `pain.001` corporate payment.
- `POST /api/v1/bangalore/logistics/optimize`: Run cash route and ATM replenishment optimization.
- `GET /api/v1/bangalore/regulatory/returns`: Generate statutory RBI returns.

### 3.3 Security & Governance Routes (`/api/v1/security`)
- `GET /api/v1/security/approvals/pending`: List actions requiring human cryptographic sign-off.
- `POST /api/v1/security/approvals/{request_id}/approve`: Cryptographically sign and release pending action.
  - **Headers**: `X-HMAC-Signature: <hmac_sha256_hex>`
  - **Request**: `{ "approver_id": string, "token": string }`
- `GET /api/v1/security/audit-trail`: Fetch immutable audit records.

### 3.4 System Health & Diagnostics (`/`)
- `GET /healthz`: Immediate liveness check for container orchestration.
- `GET /readyz`: Deep readiness probe checking DB connectivity, Redis cache, and disk write permissions.

## 5. DESIGN SYSTEM & VISUAL SPECIFICATION (TIER-1 ENTERPRISE ART DIRECTION)

### Design Philosophy:
"High-Density Terminal Meets Swiss Precision": Built for executive decision-makers, quant analysts, and enterprise procurement officers. Dark-first aesthetic with high-contrast data visualization, zero clutter, and micro-animations.

### Design Tokens:
- **Backgrounds**:
  - `bg-void`: `#050811` (Deep space black)
  - `bg-surface`: `#0a101f` (Dark obsidian card surface)
  - `bg-surface-elevated`: `#121b2d` (Elevated modals & popovers)
- **Accents & Brand Identity**:
  - `accent-emerald`: `#10b981` (Cleared cash, positive alpha, green health)
  - `accent-cyan`: `#06b6d4` (Autonomous agents, active swarms, Web3 mesh)
  - `accent-amber`: `#f59e0b` (Pending human approval, rate limit warnings)
  - `accent-rose`: `#f43f5e` (Security alerts, failed transactions, circuit breakers)
- **Typography**:
  - Headings: `font-display`: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif (700/800 tracking-tight)
  - Monospace (Financial & Data): `font-mono`: "JetBrains Mono", "Fira Code", monospace (tabular numerals enabled: `font-feature-settings: "tnum"`)
- **Accessibility & Contrast**:
  - Enforced contrast ratio >= 7:1 across all text elements (WCAG 2.2 AAA standard).
  - Full keyboard navigability with visible focus outlines (`ring-2 ring-cyan-500`).
  - Screen-reader aria attributes on every dynamic widget and live data chart.
